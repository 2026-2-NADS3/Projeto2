## Descrição do Projeto

Aplicativo Android desenvolvido como parte da disciplina de Programação Mobile.

O projeto foi desenvolvido utilizando Android Studio e tem como objetivo apresentar funcionalidades de navegação entre telas, visualização de informações e interação básica com o usuário.

---

## Tecnologias Utilizadas

- Android Studio
- Java
- XML
- ConstraintLayout
- GitBash
- GitHub

---

## Estrutura das Telas

O aplicativo possui as seguintes telas:

- MainActivity (Tela Inicial)
- Agenda
- Certificados
- Perfil
- Visualizar
- BaixarPDF

---

## Como Executar o Projeto

### 1. Clonar o Repositório

```bash
git clone <url-do-repositorio>
```

### 2. Abrir no Android Studio

1. Abrir o Android Studio.
2. Selecionar **Open**.
3. Escolher a pasta do projeto.
4. Aguardar o Gradle finalizar a sincronização.

### 3. Configuração do Emulador

Para garantir a compatibilidade e a correta visualização da interface, utilizar recomendamos o uso do seguinte dispositivo:

### Device Recomendado

✅ Pixel 9

---

## Como Testar

1. Executar o projeto pelo Android Studio.
2. Aguardar a inicialização do emulador Pixel 9.
3. Navegar pelas telas utilizando os botões disponíveis.
4. Verificar:
   - Navegação entre telas;
   - Exibição das informações;
   - Funcionamento dos botões;
   - Carregamento dos layouts.
