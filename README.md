<p align="justify">
O <strong>Próxima Etapa</strong> é um aplicativo mobile desenvolvido para apoiar os estudantes atendidos pela ONG Próxima Etapa, uma organização brasileira dedicada à democratização do acesso à educação e à orientação profissional para jovens de escolas públicas.
</p>

<p align="justify">
A aplicação tem como objetivo reunir informações, conteúdos educacionais e oportunidades de desenvolvimento pessoal e profissional em um único ambiente digital. Por meio do aplicativo, os estudantes podem acessar informações sobre cursos, orientações de carreira, eventos, workshops e atividades promovidas pela ONG.
</p>

<p align="justify">
A ONG Próxima Etapa busca preparar jovens para os desafios do mercado de trabalho e do ensino superior, oferecendo gratuitamente palestras, mentorias, oficinas e orientação vocacional. O aplicativo foi desenvolvido para ampliar o alcance dessas iniciativas e facilitar o acesso dos estudantes aos recursos disponibilizados pela organização.
</p>

---

## 📱 Funcionalidades

- Visualização de informações sobre a ONG;
- Consulta de cursos e trilhas de aprendizagem;
- Acesso a eventos, palestras e workshops;
- Navegação intuitiva entre telas;
- Interface amigável para estudantes;
- Experiência mobile desenvolvida para dispositivos Android.

## 📥 Instalação

### Requisitos

- Dispositivo Android 8.0 (API 26) ou superior;
- Arquivo APK do aplicativo.

### Instalando o APK

1. Faça o download do arquivo `ProximaEtapa.apk`;
2. Transfira o APK para o dispositivo Android, caso necessário;
3. Abra o arquivo APK;
4. Caso solicitado, habilite a opção **"Instalar aplicativos de fontes desconhecidas"**;
5. Conclua a instalação;
6. Abra o aplicativo **Próxima Etapa** e utilize normalmente.

### Executando o Projeto no Android Studio

1. Clone este repositório:

```bash
git clone https://github.com/seu-usuario/proxima-etapa.git
```

2. Abra o projeto no Android Studio;
3. Aguarde o download das dependências do Gradle;
4. Conecte um dispositivo Android ou inicie um emulador;
5. Execute o projeto através do botão **Run**.
